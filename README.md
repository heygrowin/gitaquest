# GitaQuest — Read. Reflect. Grow.

A calm, ad-free companion for your sacred Bhagavad Gita reading journey.

## ✨ Features

- **All 18 Chapters & 701 Verses**: Complete authentic Sanskrit recension, Hindi translation, and English meaning.
- **100% Offline Progressive Web App (PWA)**: Works completely offline with cached scriptures, shlokas, and commentaries.
- **Sadhana Streak & Daily Goals**: Track daily reading habits with a sacred 7-day streak tracker.
- **Bookmarks & Personal Verse Notes**: Save cherished verses and record private reflections.
- **Sacred Certificate of Completion**: Earn an official personalized certificate upon completing the entire scripture.
- **Support & Seva Integration**: Built-in Razorpay integration for voluntary contributions to keep the project free and ad-free.
- **Android APK Download & Play Store Early Access**: Option to download the signed release APK or join the official Google Play closed beta.

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS (Custom Warm Ivory `#FBF8F2` & Forest Green `#1E3A2F` Theme)
- **Icons**: Lucide React
- **Mobile Container**: Capacitor

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Run unit tests
npm run test

# Build for production (Vercel / GitHub Pages)
npm run build
```

---

## 🌐 Deploy to Vercel

1. Import this repository into [Vercel](https://vercel.com/new).
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!
